Systemanforderungen
===================

Spore benötigt mindestens:

FÜR WINDOWS XP
 * 2 GHz P4 oder gleichwertigen Prozessor
 * 512 MB RAM
 * 128 MB-Grafikkarte mit Pixel Shader 2.0-Unterstützung 
 * Die aktuellste Version von DirectX 9.0c 
 * Microsoft Windows XP Service Pack 1
 * Mindestens 4 GB verfügbaren Festplattenspeicher für die Installation sowie 1 GB weiteren Speicherplatz für Kreationen.

FÜR WINDOWS VISTA
 * 2 GHz P4 oder gleichwertigen Prozessor
 * 768 MB RAM
 * 128 MB-Grafikkarte mit Pixel Shader 2.0-Unterstützung 
 * Mindestens 4 GB verfügbaren Festplattenspeicher für die Installation sowie 1 GB weiteren Speicherplatz für Kreationen.

Auf Computern mit integriertem Grafikchip benötigt das Spiel unter Windows mindestens:
 * Intel Integrated Chipset, GMA 945 oder besser
 * Duale 2,6 GHz Pentium D CPU oder 1,8 GHz Core 2 Duo oder gleichwertig
 * 768 MB Ram

FÜR MAC OS X
 * Mac OS X 10.5.3 Leopard oder höher
 * Intel Core Duo-Prozessor
 * 1024 MB RAM
 * ATI X1600 oder NVIDIA 7300 GT mit 128 MB Grafik-RAM, oder Intel Integrated GMA X3100
 * Mindestens 4 GB verfügbaren Festplattenspeicher für die Installation sowie 1 GB weiteren Speicherplatz für Kreationen.

 Dieses Spiel läuft nicht auf PowerPC (G3/G4/G5)-basierten Mac-Systemen oder eingebauten Grafikkarten der
 GMA 950-Serie.

Laptopversionen dieser Chipsätze funktionieren zwar unter Umständen, verringern allerdings möglicherweise die Spielgeschwindigkeit. Standalone-Karten, einige GeForce FX-Modelle, die über einen gewöhnlichen PCI-Steckplatz installiert werden (also nicht über PCIe, PCIx oder AGP), erzielen eine schlechte Performance. Integrierte Grafikchipsätze von Intel sind mit untertakteten Bauteilen, wie der 945GU, GML and GMS ausgestattet und werden daher keine ausreichende Performance bringen.

Integrierte Chipsätze, wie ATI Xpress und NVIDIA TurboCache-Modelle, wählen automatisch niedrige Einstellungen, mit denen sie zufriedenstellende Ergebnisse liefern sollten.

Wenn du versuchst, das Spiel mit anderen als den oben genannten Grafikkarten zu spielen, treten möglicherweise Leistungs- oder Grafikprobleme auf. Unter Umständen lässt sich das Spiel gar nicht spielen.

Die NVIDIA GeForce FX-Serie wird unter Windows Vista nicht unterstützt.


Bekannte Hardware-Probleme
===================

Beim Bemalen deiner Kreatur oder beim Wechsel zwischen Vollbild und Fenstermodus reagiert das Spiel unter Umständen nicht mehr. Um dieses Problem zu beheben, lade vom Hersteller deiner Grafikkarte die aktuellsten Grafiktreiber herunter.

Wenn du die Anzeige-Einstellungen änderst, kann es vorkommen, dass dein Monitor nicht auf eine eigentlich unterstützte Auflösung reagiert und stattdessen ein schwarzes oder verzerrtes Bild anzeigt. Wechsle bitte in diesem Fall mit Alt-Enter in den Fenstermodus und wähle dann niedrigere Werte für die Auflösung und die Bildwiederholrate.

Soundhardwarebeschleunigung wird nicht unterstützt.

Windows Vista:
Unter Microsoft Vista erscheint beim Start des Spiels unter Umständen eine Warnung, dass nicht genug Adressraum vorhanden ist, und es wird ein Link zur Microsoft Knowledge Base angezeigt. Wird diese Nachricht bei dir angezeigt, solltest du die Anweisungen befolgen und die verlinkte Website besuchen, um dein System zu aktualisieren.

Turtle Beach Montego DDL–Surround 5.1 wird nicht unterstützt. 
Dieser Modus kann zwar in den Optionen ausgewählt werden, der Ton wird aber für alle Lautsprecher in Stereo (2-Kanal) ausgegeben.

Mac OS X:
Auf Mac OS X-Systemen mit NVIDIA-Karten mit weniger als 256 MB Grafik-VRAM kann es erforderlich sein, die Grafikqualität herabzusetzen, wie unter den Tipps zur Grafikqualität beschrieben.

Auf einem Mac Book Pro mit aktivierten synchronisierten Bildschirmen muss eine Auflösung gewählt werden, die von internen wie externen Bildschirmen unterstützt wird. Das Problem kann umgangen werden, indem sicher gestellt wird, dass der interne LCD-Bildschirm der Haupt-Systembildschirm ist, bevor die synchronisierten Bildschirme aktiviert werden. Die korrekten Auflösungen werden dann eingestellt.

Unter Umständen wird kein Audio mehr wiedergegeben, wenn nach Spielstart Kopfhörer angeschlossen werden.
Um dies zu vermeiden, sollten Kopfhörer bereits vor Spielbeginn an den Mac angeschlossen werden.

Falls während der Verwendung von ATI X1600 oder X1900-Karten Probleme mit der Framerate auftreten, ändere die Einstellungen für die Beleuchtungsqualität auf "Niedrig".

Performance-Tipps
===================

Wenn du Spore zum ersten Mal öffnest, wählt das Spiel automatisch die optimalen Optionen für deine Grafikkarte, deinen Prozessor und deine Soundkarte. Möchtest du die Leistung des Spiels verbessern, senke die Grafik-Einstellungen im Optionen-Menü auf "Mittel" oder "Niedrig".

Ferner kannst du die Leistung des Spiels durch eine Senkung der Auflösung auf 1024x768 oder 800x600 optimieren. Spiele Spore nicht mit maximaler Auflösung, wenn du einen Monitor mit 1600 (oder mehr) Pixeln in der Breite hast.

Spore ist ein Echtzeit-3D-Spiel, das einen Großteil der Rechenleistung deines PCs beansprucht. Andere Programme, die im Hintergrund ausgeführt werden, könnten das Spiel verlangsamen oder zu Aussetzern führen. Für die beste Leistung beende bitte alle überflüssigen Programme, die im Hintergrund ausgeführt werden, wenn du Spore spielst.

Der Vollbildmodus läuft im Allgemeinen flüssiger als der Fenstermodus.

Spiel-Installation
----------------

Windows: (CD-Benutzer):
 * Lege die CD/DVD in dein CD-/DVD-ROM-Laufwerk ein und folge den Bildschirmanweisungen.
 * Nach der Installation kannst du das Spiel im Startmenü anklicken. 
 * Bei Windows Vista(tm) ist das Spiel unter START im Menüpunkt SPIELE zu finden. Wähle bei älteren Windows(tm)-Versionen im nun erscheinenden Menü den Eintrag PROGRAMME (oder ALLE PROGRAMME).

Windows (Benutzer von EA Store):
 * Wenn der Download durch den EA Download Manager abgeschlossen wurde, erscheint ein Installations-Icon. Klicke auf das Icon und folge den Anweisungen auf dem Bildschirm.
 * Starte nach Installationsende das Spiel direkt im EA Download Manager.

Mac OS X:
 * Lege die Disc in das CD/DVD-ROM-Laufwerk. Ein CD-Symbol, welches das Spiel darstellt, erscheint auf dem
   Schreibtisch. Doppelklicke auf das Symbol, um den Launcher des Spiels zu starten.
 * Wähle im Launcher des Spiels das Installations-Symbol, um das Installationsmenü aufzurufen. 
 * Folge den Bildschirmanweisungen, um die Installation abzuschließen.

Deinstallation des Spiels
----------------

Windows XP:
 * Öffne "Programme hinzufügen oder entfernen" in der Systemsteuerung.
 * Klicke auf "Programme ändern oder entfernen".
 * Klicke auf den Programmeintrag "Spore".
 * Klicke auf "Entfernen". 
 * Folge den Bildschirmanweisungen, um die Deinstallation abzuschließen.

Windows Vista:
 * Öffne die "Programme und Features"-Steuerung. 
 * Klicke auf den Programmeintrag "Spore". 
 * Klicke auf "Deinstallieren". 
 * Folge den Bildschirmanweisungen, um die Deinstallation abzuschließen.

Mac OS X:
 * Du musst mit einem Konto angemeldet sein, das über Administratorrechte verfügt.
 * Lösche den "Spore"-Ordner aus deinem Anwendungs-Ordner.
 * Zusätzliche Dateien befinden sich unter /Benutzer/<Benutzername>/Library/Preferences/Spore-Preferences.
* Um in Spore erstellte Inhalte zu löschen, entferne folgenden Ordner
   /Benutzer/<Benutzername>/Dokumente/MeinSPORE-Kreationen

Speicherpfade auf der Festplatte
-----------------

Spore speichert deine Kreaturen, Filme, Bilder und animierte Avatare im Ordner "MeinSPORE-Kreationen". Der Ort dieses Ordners ist abhängig vom verwendeten Betriebssystem:

Windows XP:
* “MeinSPORE-Kreationen” befindet sich im "Eigene Dateien"-Ordner. 

Windows Vista:
* “MeinSPORE-Kreationen” befindet sich im "Dokumente"-Ordner.

Mac OS X:
* “MeinSPORE-Kreationen” befindet sich im "Dokumente"-Ordner. 

Spore legt auf deiner Festplatte einen Zwischenspeicher (Cache) für Grafikobjekte an, die du heruntergeladen hast. Ist der verfügbare Speicherplatz auf deiner Festplatte begrenzt, kannst du die Größe des Zwischenspeichers in den Grafikoptionen verringern.


Steuerung und Schnelltasten
===========================

- Kreaturen Editor -

Linksklick, um Teile auszuwählen und zu bewegen.

Linksklick, um die pfeilförmigen Griffe auf dem ausgewählten Teil zu bewegen und so dessen Form zu verändern.

Linksklick, um Teile von der Kreatur zu ziehen und zu verkaufen.

Maus über Teil oder Wirbel bewegen und mit dem Mausrad die Größe verändern. Alternativ dazu Teil auswählen und Größe mit Pfeil oben/unten verändern.

Alt bei Klick auf Teil gedrückt halten, um dieses zu kopieren. Auf Mac-Systemen: Option bei Klick auf Teil gedrückt halten.

Linksklick auf Wirbelsäule und Maus bewegen, um Form der Wirbelsäule zu verändern. Wirbelsäule mit Pfeilen verkürzen oder verlängern.

Linksklick auf Oberkörper (nicht auf die Wirbelsäule), um diesen zu bewegen.

Strg gedrückt halten, um Gliedmaßen zu verschieben und an anderer Stelle anzubringen.

Tab gedrückt halten, wenn ein Teil ausgewählt ist, um zusätzliche Rotationsgriffe einzublenden.


- Gebäude Editor -

Um ein Teil vertikal zu verschieben, halte Steuerung gedrückt, klicke das Teil an und verändere seine Position mit der Maus.

Um ein Teil auf dem Podium zu bewegen, halte Shift gedrückt klicke das Teil an und verändere seine Position mit der Maus.


- Fahrzeug Editor -

Korpus und Cockpitteile werden automatisch unter der Mitte des Fahrzeugs justiert.

Jedes Fahrzeug unterliegt Höhen- und Breitenbeschränkungen. 

Um das gesamte Fahrzeug zu bewegen, halte Shift gedrückt und verändere seine Position mit der Maus. 


- Kamera -

Linksklick auf den Hintergrund, um die Kamera zu bewegen.

Mausrad im Testlauf, um die Kamera zu zoomen.

Shift und Mausrad im Teile- und Malen-Modus, um die Kamera zu zoomen.

, und . Kamera drehen
+ und - Heran-/wegzoomen

- Allgemein - 

Strg+N = Neue Kreatur
Strg+Y = Wiederholen
Strg+Z = Rückgängig
Strg+S = Kreatur speichern
Strg+H = Benutzeroberfläche aus-/einblenden
H oder ? = Spore-Fibel öffnen/schließen
B = Sporepädie öffnen
Alt-Enter = Zwischen Fenster- und Vollbildmodus wechseln


Windows:
Alt-Enter    Zwischen Fenster- und Vollbildmodus wechseln.

Mac OS X:
Befehltaste + Returntaste:  Zwischen Fenstermodus und Vollbildmodus wechseln.
Befehltaste + Tab-Taste:  Spiel im Vollbildmodus minimieren.

Bitte beachte, dass das Spiel nicht pausiert, während es minimiert ist, sondern im Hintergrund weiterläuft.


- Funktionen der rechten Maustaste unter Mac OS X -

Dieses Spiel enthält Features, die eine rechte Maustaste erfordern. Benutzt du eine Apple Mighty Mouse, kannst du die rechte Maustaste unter Systemeinstellungen->Tastatur & Maus aktivieren. Ändere das "Rechtsklick"-Dropdown-Menü zu "Zweite Taste". 

Um mit der Apple Mighty-Maus das Klicken beider Maustasten zu simulieren, das Mausrad gedrückt halten oder die liknke Maustaste drücken und gleichzeitig Control und Alt gedrückt halten.

Die meisten PC-USB-Mäuse werden auf dem Macintosh ebenfalls unterstützt. Rechte und linke Maustaste werden beim Anschließen der Maus erkannt und funktionieren ordnungsgemäß. 

Benutzt du eine herkömmliche Apple-Maus mit nur einer Taste oder ein MacBook Pro, das lediglich über ein Track-Pad verfügt, kannst du eine rechte Maustaste simulieren, indem du die Befehltaste gedrückt hältst, während du die Maustaste klickst. 

Um mit der Maus mit nur einer Taste das Klicken beider Maustasten zu simulieren, gleichzeitig Control und Alt gedrückt halten, während du die Maustaste klickst.


Befehlszeilenoptionen
--------------------

Folgende Befehlszeilenoptionen werden unterstützt:
 -w    Fenstermodus
 -f    Vollbildmodus

Cheats
------

Möchtest du im Spiel Cheats eingeben, öffne zunächst mit Strg+Shift+C die Befehlskonsole. Um die Befehlskonsole zu schließen, drücke Enter. Folgende Cheats sind (unter anderem) verfügbar:

help: Listet alle Cheats des Spiels auf.
help [cheatname]: Zeigt Informationen zum jeweiligen Cheat an.
Quit: Beendet das Spiel.
