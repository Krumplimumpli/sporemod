Systemkrav
==========

Spore kräver minst:

FÖR WINDOWS XP

 * 2.0 GHz P4-processor eller motsvarande
 * 512 MB RAM
 * Ett 128 MB grafikkort med stöd för Pixel Shader 2.0 
 * Senaste versionen av DirectX 9.0c
 * Microsoft Windows XP Service Pack 1
 * Minst 4 GB hårddiskutrymme med minst 1 GB
   ytterligare utrymme för skapelser.

FÖR WINDOWS VISTA
 * 2.0GHz P4-processor eller motsvarande
 * 768 MB 
 * Ett 128 MB grafikkort med stöd för Pixel Shader 2.0 
 * Minst 4 GB hårddiskutrymme med minst 1 GB
   ytterligare utrymme för skapelser.

För datorer med integrerade grafik-chipset i Windows
kräver spelet minst:
 * Intel Integrated Chipset, GMA 945GM eller bättre.
 * 2,6 GHz Pentium D CPU eller 1,8 GHz Core 2 Duo eller motsvarande
 * 768 MB RAM

FÖR MAC OS X
 * Mac OS X 10.5.3 Leopard eller högre
 * Intel Core Duo-Processor
 * 1024 MB RAM
 * ATI X1600 eller Nvidia 7300 GT med 128 MB grafikRAM 
   eller Intel Integrated GMA X3100
 * Minst 4 GB hårddiskutrymme, samt minst 1 GB
   ytterligare utrymme för skapelser.

Detta spel fungerar inte på PowerPC(G3/G4/G5)-baserade Mac-datorer 
eller GMA 950-klassen av integrerade grafikkort.

Versioner av dessa chipset installerade i bärbara datorer
kan fungera, men kan eventuellt gå ganska långsamt.
Instickskort som är installerade på vanliga PCI-platser
(inte PCIe, PCIx eller AGP), som exempelvis vissa varianter av GeForce FX,
kommer att fungera dåligt. Integrerade Intel-chipsets med underklockade
delar, som 945GU, GML och GMS, fungerar inte tillfredsställande.

TurboCache-varianterna kommer att fungera tillfredsställande,
men på låga inställningar.

Observera att försök att spela spelet med grafikhårdvara
som inte finns med i listan ovan kan resultera i dåliga prestanda,
grafikproblem eller att spelet inte fungerar alls.

NVIDIA GeForce FX-serien stöds inte under Vista.


Kända hårdvaruproblem
=====================

Spelet kan svara långsamt på kommandon när du målar din varelse
eller efter att du växlat mellan fullskärm och fönsterläge.
För att åtgärda detta, uppdatera dina grafikdrivrutiner
från försäljarens hemsida.

När du ändrar skärmupplösning kan det hända att skärmen
inte svarar på en upplösning den enligt dokumentationen
ska stödja. Bilden blir svart eller förvrängd. Om det händer,
tryck Alt-Enter för att växla till fönsterläge och ändra
sedan upplösning och uppdateringsfrekvens tillbaka 
till lägre värden.

Hårdvaruaccelererat ljud stöds inte.

Windows Vista:
När spelet startas kan en del Windows Vista-användare
få en varning om att de håller på att få slut på
adressutrymme samt en länk till Microsoft Knowledge Base.
Om du ser det här meddelandet rekommenderas det att du
följer instruktionerna och besöker den angivna hemsidan
för att uppdatera din dator.

Turtle Beach Montego DDL - Surround 5.1 stöds ej. 
Detta ljudläge finns tillgängligt bland alternativen
men ljudet blir i stereo (2 kanaler) för alla högtalare.

Mac OS X:
På Mac OS X-datorer som har NVIDIA-kort med mindre än 
256 MB VRAM kan du behöva sänka grafikkvaliten 
med de metoder som beskrivs i Allmän felsökning. 

Om du kör spelet på en Mac Book Pro med skärmspegling 
påslagen, se till att du väljer en upplösning som stöds 
av både den interna och den externa skärmen. 
Ett sätt att kringgå problemet är att se till att den 
interna LCD-skärmen är datorns huvudskärm innan du slår 
på skärmspegling. De rätta upplösningarna visas för dig. 

Om du kopplar in hörlurar medan spelet är igång kan det hända att
ljudet stängs av. Se till att dina hörlurar är inkopplade innan du
startar spelet för att undvika detta problem.

Om du upplever problem hackig och/eller långsam grafik när du kör 
på ett ATI X1600 eller X1900-kort, ställ ner Ljussättningskvaliteten till Låg.


Prestandatips
================

När du kör Spore för första gången kommer spelet automatiskt 
att välja de lämpligaste alternativen för din kombination av 
grafikkort, CPU och ljudkort. Du kan förbättra prestandan 
genom att sänka inställningarna till "medel" eller "låg" på
alternativ-kontrollpanelen.

Du kan även förbättra spelets prestanda genom att
sänka spelets upplösning till 1024 x 768 eller 800 x 600.
Det rekommenderas inte att köra på full skärmupplösning
om din skärmupplösning har minst bredden 1600.

Spore är ett 3D-spel i realtid som kräver huvuddelen av 
din dators processorkraft. Andra program som körs i bakgrunden 
kan få det att gå långsammare eller hacka. För bästa resultat, 
se till att stänga av bakgrundsprogram när du spelar Spore.

Helskärmsläge ger generellt bättre prestanda än fönsterläge.

Felmeddelanden från Spore
--------------------

Här är några fel- och varningsmeddelanden du kan få från spelet,
samt några förslag på hur du ska lösa problemen.

1000:  En annan Spore-process körs redan.
       Var god avsluta eller döda den först.

1001:  Spelet kan inte hitta några giltiga skärminställningar.
       Var god se till att grafiken är inställd på 32-bitars färg.

1002:  Direct X finns inte installerat. Var god installera det,
       eller ominstallera spelet.
       
1004:  Spelet kan inte hitta sin datamapp. 
       Var god ominstallera spelet.

1010   Det rekommenderas att du uppdaterar drivrutinerna till
       ditt grafikkort för att undvika kompatibilitets-problem.
       Det kan du oftast göra via hårdvarutillverkarens webbsajt.
       NVIDIA, ATI, och Intel har sajterna:
       
         http://www.nvidia.com/content/drivers/drivers.asp
         http://ati.amd.com/support/driver.html
         http://support.intel.com/support/graphics/

1011:  Det krävs att du uppgraderar drivrutinerna till ditt 
       grafikkort för att undvika allvarliga problem med spelet.
       Se ovan.

1012:  Spelet har problem med det här kortet i multi-GPU-läge.
       Var god uppdatera dina drivrutiner, eller stäng av
       multi-GPU-läget via försäljarens kontrollpanel.

2001:  Datorn uppfyller inte våra minimikrav 
       och kan inte köra spelet alls.

2002:  Datorn uppfyller inte våra minimikrav 
       och du kan uppleva problem med grafik, prestanda eller ljud.
       
2003:  Du kör en version av Vista som har problem med
       grafikkort med mycket VRAM. 
       Var god uppdatera till SP1, 
       eller installera motsvarande fix från

         http://support.microsoft.com/default.aspx/kb/940105

Installera spelet
------------------

Windows (användare med skiva):
 * Stoppa in skivan i din skivenhet och följ instruktionerna på skärmen.
 * När spelet har installerats kan du starta det genom att lokalisera spelet 
   via Startmenyn. 
 * Spel under Windows Vista™ finns i menyn Start > Spel och under 
   tidigare versioner av Windows™ i menyn Start > Program (eller Alla program).

Windows (EA Store-amvändare):
 * När spelet har laddats ner av EA Download Manager, klicka på installations- 
   ikonen som visas och följ instruktionerna op skärmen. 
 * Starta spelet (när det är installerat) direkt från EA Download Manager.

Under Windows Vista Classic Startmeny-stil finns spel i menyn 
Start > Program > Soel > Games Explorer.

Mac OS X:
 * Sätt i spelskivan i din CD/DVD-läsare. En CD-ikon 
   kommer att visas på ditt skrivbord. Dubbelklicka på 
   ikonen för att starta spelets startprogram.
 * Välj spelets installationsikon längst ned i 
   startprogrammet för att visa installationsmenyn.
 * Följ instruktionerna som visas på skärmen för att 
   fullborda installationen.

Filmapp
-----------------

Spore lagrar dina varelser, filmer, bilder
och animerade avatarer i din “Mina dokument”-mapp,
i mappen "Mina Sporeskapelser" ("My Spore Creations"). 
Var mappen finns beror på ditt operativsystem:

Windows XP:
* “Mina Sporeskapelser” finns i mappen “Mina dokument”. 

Windows Vista:
* “Mina Sporeskapelser” finns i mappen “Dokument”.

Mac OS X:
* “My Spore Creations” finns i mappen “Documents”.


Spore lagrar även en cache med pollinerat material som 
du har laddat ned. Om du har ont om hårddiskutrymme, 
kan du minska storleken på den cachen i grafikalternativen. 


Kommandon och Genvägar
----------------------

- Creature Creator (Varelseskaparen) -


Vänsterklicka för att markera och flytta delar.

Vänsterklicka för att flytta de pilformade handtagen
på den markerade delen, vilket ändrar delens form.

Vänsterklicka och dra bort delar för att sälja tillbaka dem.

För markören över en del eller en kota och använd mushjulet
för att justera storleken, eller använd pil upp och pil ner.

Håll ner Alt när du klickar och drar en del för att kopiera den. På
Mac-system använder du Option-tangenten i stället för Alt.

Vänsterklicka och dra direkt på ryggraden för att ändra
ryggradens form. Använd pilarna för att förlänga eller förkorta
ryggraden.

Vänsterklicka på bålens skinn (inte ryggraden) för att flytta den.

Håll ner Ctrl när du drar ett lemsegment för att sätta fast det
på en annan lem.

Håll ner Tab när en del är markerad för att visa ytterligare
vridhandtag.

- Byggnadskaparen -

För att flytta en del i höjdled, tryck och håll ner Ctrl när du klickar 
på en del och flyttar den med musen.

För att flytta en del över podiets yta, tryck och håll ner Skift
medan du klickar på en del och flytta den med musen.


- Fordonskaparen -

Chassi- och cockpitdelar placeras automatiskt längs fordonets mittlinje.

Det finns gränser för ett fordons höjd och diameter.

För att flytta hela fordonet, tryck och håll ner Skift medan du rör på musen. 


- Kamera –

Vänsterklicka på bakgrunden för att flytta omkring kameran.

I provkörläget zoomar mushjulet kameran in och ut.

I del- och målalägena zoomas kameran med skift + mushjulet.

, och .     Vrider kameran

+ och -     Zoomar in och ut

- Allmänt –

Ctrl-N      Påbörja ny varelse
Ctrl-Y      Gör om
Ctrl-Z      Ångra
Ctrl-S      Spara varelse
Ctrl-H      Slå på/av gränssnittet
H eller '   Öppna eller stäng Sporeguiden
B           Öppna Sporeopedin


Windows:
Alt-Enter    Växla mellan fönsterläge och helskärmsläge. 

Mac OS X:
Command + Return:  Växla mellan fönsterläge och helskärm. 
Command + Tab:	 Minimera spelet i helskärmsläge.


Observera att när spelet är minimerat pausar det inte, 
det fortsätter att köra i bakgrunden.


- Höger musknapp i Mac OS X -

Detta spel innehåller funktioner som kräver en högerknapp 
på musen. Om du har en Mighty Mouse, kan du aktivera 
högerknappen i System Preferences->Keyboard and Mouse.
Ändra menyalternativet för ”Right Click” till Secondary Button. 

För att emulera att klicka med båda knapparna samtidig med en 
Apple Mighty Mouse, håll ner blädderknappen eller klicka med 
vänster musknapp medan du håller ner Command- och Optiontangenterna.

Dessutom stöds de flesta USB-möss till PC av Macintosh. 
Vänsterknappen och högerknappen detekteras och fungerar korrekt
på dessa möss när de ansluts för första gången. 

Om du har en Apple-mus med bara en knapp eller en MacBook Pro
med bara en pekplatta, kan du emulera en högerknapp
genom att hålla ner kommandoknappen medan du klickar 
med musknappen. 

För att emulera att klicka med båda knapparna samtidigt med en enknappsmus, 
håll ner Command och Optionknapparena medan du klickar med musknappen.

Kommandoradsalternativ
----------------------

Följande kommandoradsalternativ stöds:

  -w     Kör i fönsterläge.
  -f     Kör i fullskärmsläge.
  -r:<width>x<height> 
         Kör med angiven upplösning.
  -safe  Tvinga fram ett minimum av konfigurationsalternativ
         och ladda inga valfria moduler.


Fusk

------

För att skriva in fusk i spelet, öppna först kommandokonsollen
genom att trycka på Ctrl-Skift-C samtidigt. Tryck på Enter
för att stänga kommandokonsollen.

Några av de fusk som kan användas är:

help: visar alla fusk i spelet.
help [cheatname]: visar specifik information om fusket.
quit: avsluta spelet.


Kompatibilitet
==============

Spore är designat för att köras på Windows XP-kompatibla 
grafik- och ljudkort. Drivrutiner för dessa tillhandahålls
av korttillverkarna, vilket kan leda till 
kompatibilitetsproblem som vi inte råder över.

Om du upplever några problem rekommenderas det alltid att du skaffar
och installerar de senaste drivrutinerna till din hårdvara.
De flesta tillverkare har drivrutinerna tillgängliga
för nerladdning på sina hemsidor. 


Mer information om kända tekniska problem finns på http://www.spore.com.
